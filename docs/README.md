# Documentation

This directory contains templates and documentation for the GIS maps repository.

## Templates

The `templates/` directory contains templates for documenting your maps and data:

- **MAP_TEMPLATE.md**: Template for documenting individual map projects
- **DATA_TEMPLATE.md**: Template for documenting datasets

## Using Templates

1. Copy the appropriate template to your project directory
2. Rename it to `README.md`
3. Fill in all relevant sections
4. Remove any sections that don't apply (but try to keep most information)

## Documentation Guidelines

### For Maps

Every map project should include:
- Clear title and description
- Data sources with URLs
- Layer information
- Software and version used
- Export information
- Any special requirements or notes

### For Data

Every dataset should be documented with:
- Source and download information
- Coordinate reference system
- License and usage rights
- Known limitations or issues
- Processing steps (if modified)

## Additional Documentation

Consider adding:
- Methodology notes for complex analyses
- Style guides for consistent map production
- Tutorials or guides for common tasks
- References to external resources

## Best Practices

- Keep documentation up to date
- Be thorough but concise
- Include dates (creation, updates)
- Link to related resources
- Use clear, professional language
